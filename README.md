# High-Load Async Telegram Prediction Platform (TON / Parimutuel Engine)

Высоконагруженная асинхронная финтех-платформа в виде Telegram Mini App с интеграцией блокчейна TON, реализованная по модели пари-мутуэль. Проект спроектирован с упором на отказоустойчивость, финансовую точность, защиту от фрода и высокую скорость обработки транзакций.

---

## 🛠 Стек технологий

* **Язык:** Python 3.11+
* **Telegram Bot Framework:** aiogram 3.x (Async)
* **База данных & ORM:** PostgreSQL, SQLAlchemy 2.0 (Async), asyncpg, Alembic (миграции)
* **Кэширование & Очереди:** Redis
* **Блокчейн / Web3:** Интеграция с TON, отслеживание ончейн-балансов, оракулы котировок

---

## 📐 Архитектура и ключевые решения

1. **Финансовая точность (`Numeric(20, 8)`):**
   * Все денежные расчеты, ставки, пулы и балансы хранятся и обрабатываются с использованием фиксированной точности `Numeric(20, 8)`, что полностью исключает ошибки округления с плавающей точкой (`float`), критичные для финансовых систем.

2. **Идемпотентность транзакций (`idem_key`):**
   * Реализован механизм защиты от дублирования транзакций и повторных списаний при сетевых сбоях или повторных запросах пользователя через уникальные ключи идемпотентности (`idem_key`).

3. **Изоляция балансов и защита от кассовых разрывов:**
   * Жесткое разграничение пользовательских средств и операционных балансов платформы. Фоновые воркеры непрерывно сверяют реальный ончейн-баланс кошелька с обязательствами в базе данных, мгновенно генерируя системные алерты при любых расхождениях.

4. **Транзитная реферальная система:**
   * Многоуровневая реферальная логика с начислением бонусов исключительно с реальных проигрышей участников, с проверкой связей на мультиаккаунтинг и фрод.

5. **Модуль антифрода (`AnomalyDetector` и `SecurityManager`):**
   * Система поведенческого анализа отслеживает аномальную активность: временную кластеризацию ставок, попытки манипуляции пулами на последней секунде раунда и скоринг рисков с автоматическим переходом в защитный режим (понижение лимитов).

## 🚀 Нагрузочное тестирование

Проект прошел стресс-тест-симуляции:
* **Пропускная способность:** 10 000 – 20 000 одновременных асинхронных запросов.
* **Отказоустойчивость:** Использование Redis в качестве буфера состояний позволило избежать блокировок базы данных (Deadlocks) при пиковых нагрузках на раундах.

## 📂 Структура проекта

```text
├── bot/
│   ├── handlers/        # Обработчики команд и состояний Telegram (aiogram 3)
│   ├── keyboards/       # Генерация клавиатур и интерфейса Mini App
│   └── middlewares/     # Middleware для авторизации, троттлинг-защиты и сессий
├── database/
│   ├── models.py        # SQLAlchemy 2.0 модели (User, Bet, Pool, Transaction)
│   └── session.py       # Асинхронный пул подключений (asyncpg)
├── services/
│   ├── financial.py     # Ядро пари-мутуэль и расчет коэффициентов
│   ├── ton_client.py    # Взаимодействие с блокчейном TON и кошельками
│   └── worker.py        # Фоновые воркеры сверки балансов и закрытия раундов
├── security/
│   └── antifraud.py     # AnomalyDetector и SecurityManager
├── alembic/             # Миграции базы данных
├── .env.example         # Шаблон конфигурации окружения
├── config.py            # Загрузка настроек и валидация через Pydantic
└── main.py              # Точка входа приложения
⚙️ Установка и запуск (для разработчиков)
Клонируйте репозиторий:
git clone [https://github.com/rimskii15/название-твоего-репозитория.git](https://github.com/rimskii15/название-твоего-репозитория.git)
cd название-твоего-репозитория
Создайте и активируйте виртуальное окружение:
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
Установите зависимости:
pip install -r requirements.txt
Создайте файл .env на основе шаблона .env.example и заполните необходимые параметры (токен бота, доступы к PostgreSQL и Redis).
Запустите миграции базы данных:
alembic upgrade head
Запустите приложение:
python main.py
